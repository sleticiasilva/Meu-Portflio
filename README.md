
# Portfólio — Letícia Frederico

Portfólio pessoal de desenvolvimento web, com projetos desenvolvidos em HTML, CSS e JavaScript.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Estrutura do projeto
- `index.html`: estrutura e conteúdo do site.
- `style.css`: identidade visual, layout e responsividade.
- `script.js`: interações, menu mobile e personalização dos links.
- `imagem/`: imagens utilizadas no portfólio.

## Projetos
- Aura Estética
- Glow Up

## Executar localmente
Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server do VS Code.

## Publicação
Projeto estático que pode ser publicado na Vercel, conectado diretamente ao GitHub. Não necessita de comando de build.
